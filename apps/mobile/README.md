# HowlAlert Mobile (iOS + watchOS)

One Xcode project with two app targets (iOS app + watchOS app), bundled so they
install together. Paid. Push notifications, Live Activity, Dynamic Island crit
bar, watch complications + Smart Stack widget.

- Targets **iOS 26.0+ / watchOS 26.0+** only.
- Imports `packages/HowlAlertUI` via a local Swift Package reference.

See HAA-87 / HAA-91.
