## What it is

HowlAlert is a small macOS menu bar app for people who live in Claude Code. It
watches the usage files Claude Code already writes to `~/.claude`, rebuilds your
rolling 5-hour usage window, and turns it into something you can act on:
**"Runs out in 47m."**

It never connects to Anthropic's services and never sees your prompts or code —
it only reads the local usage totals already on your Mac.
