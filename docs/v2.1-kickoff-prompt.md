## 2. What HowlAlert is
Three surfaces + a relay:
- Desktop app (`apps/macos`) — SwiftUI menu bar app. Watches `~/.claude/` via FSEvents + Stop hook. Free. Notarized DMG via Homebrew cask.
- Mobile app (`apps/mobile`) — ONE Xcode project, iOS + watchOS targets. Paid. Push, Live Activity, Dynamic Island, complications + Smart Stack.
- Server (`apps/server`) — Hono on Bun, deploys to Dokploy. APNs relay. Postgres + Redis.
- Admin (`apps/web`) + Docs (`apps/docs`).
Inspired by CodexBar (MIT). Edge: push to iPhone/Watch, Dynamic Island, watch complications, Stop-hook driven.

## 4. Tech stack (non-negotiable)
- Desktop: Swift 6 / SwiftUI, `LSUIElement`, FSEvents + Hardened Runtime + Developer ID notarization.
- Mobile: Swift 6 / SwiftUI, one Xcode project, iOS + watchOS targets.
- Shared Swift UI: `packages/HowlAlertUI` — tokens + 20 components.
- Server: Hono on Bun → Dokploy. Postgres + Drizzle. Redis (APNs JWT 50min TTL, replay nonces, throttle, rate limits).
- Admin: Next.js 15 + tRPC + better-auth. Docs: fumadocs. Monorepo: Turborepo + Bun.
- Auth: macOS→server = HMAC-SHA256 over CloudKit-shared secret. Push: APNs HTTP/2, ES256 JWT in Redis. IAP: RevenueCat. Updates: Sparkle 2.x (EdDSA).

## 5. Monorepo layout
Everything buildable in `apps/`. Shared in `packages/`. Bun workspaces glob ONLY JS dirs (exclude Swift). Exactly two Xcode projects: `apps/macos` (desktop), `apps/mobile` (iOS + watch). Both import `packages/HowlAlertUI`.
